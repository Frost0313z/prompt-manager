# 프롬프트 매니저 (Prompt Manager)

터미널에서 메뉴를 선택해 나만의 AI 프롬프트를 등록하고 관리하는 콘솔 프로그램입니다.
Codyssey 대전 캠퍼스 "Python & Git 기초" 미션 결과물입니다.

## 실행 방법

```bash
python main.py
```

Python 3.10 이상이 필요하며, 외부 라이브러리는 사용하지 않습니다.

## 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목/내용/카테고리를 입력해 새 프롬프트를 등록합니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택해 해당 프롬프트만 조회합니다. |
| 4 | 프롬프트 검색 | 제목/내용에 포함된 키워드로 검색합니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 프롬프트 전체 내용을 확인합니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 켜고 끕니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 봅니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 실행 중에만 유지되며, 종료하면 초기화됩니다.
시작 시 이전 미션에서 작성한 프롬프트 3개가 기본 데이터로 등록되어 있습니다.

## 카테고리

`텍스트 생성` · `이미지 생성` · `영상 생성` · `페르소나` · `자동화` · `기타`

## 프로젝트 구조

```
prompt-manager/
├── main.py                 # 실행 진입점
└── prompt_manager/
    ├── __init__.py
    ├── data.py              # 기본 프롬프트 데이터, 카테고리 목록
    └── core.py              # 메뉴 및 기능별 함수
```
